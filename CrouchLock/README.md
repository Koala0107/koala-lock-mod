# CrouchLock

Minecraft 1.20.4 + Fabric용 잠금 모드입니다. 전용 열쇠를 든 채 웅크리고 블록을 우클릭하면 잠깁니다.

## 필요한 모드

- Minecraft 1.20.4
- Fabric Loader 0.15.11 이상
- Fabric API 0.97.2+1.20.4 이상
- Java 17

## 열쇠 조합법

작업대에 아래처럼 놓으면 `잠금 열쇠` 1개를 얻습니다.

| 1열 | 2열 | 3열 |
| --- | --- | --- |
| 빈칸 | 철괴 | 철괴 |
| 빈칸 | 레드스톤 가루 | 빈칸 |
| 빈칸 | 막대기 | 빈칸 |

필요 재료: 철괴 2개, 레드스톤 가루 1개, 막대기 1개.

## 사용법

1. 잠금 열쇠를 제작합니다.
2. 열쇠를 들고 웅크린 상태에서 상자·문·덫문·통 등을 우클릭하면 잠깁니다.
3. 잠긴 블록은 해당 열쇠를 손에 들고 평소처럼 우클릭해야 사용할 수 있습니다.
4. 같은 열쇠를 들고 다시 웅크린 채 우클릭하면 잠금이 해제됩니다.
5. 잠긴 블록은 해당 열쇠를 주 손이나 보조 손에 들지 않으면 파괴할 수 없습니다.

열쇠마다 첫 사용 시 고유 코드가 생성됩니다. 여러 열쇠를 만들어 서로 다른 블록에 사용할 수 있으며, 한 열쇠로 여러 블록을 잠그는 것도 가능합니다. 큰 상자는 양쪽이 함께 잠기고, 문은 위·아래 칸이 함께 잠깁니다. 권한 레벨 2 이상의 서버 운영자는 긴급 관리를 위해 잠금을 우회할 수 있습니다.

## 빌드

Gradle 8.6과 Java 17을 준비한 뒤 프로젝트 폴더에서 실행합니다.

```bash
gradle build
```

완성된 모드 파일은 `build/libs/crouchlock-1.0.0.jar`입니다. 이 JAR과 Fabric API를 클라이언트 및 서버의 `mods` 폴더에 넣으세요.

## 비공개 GitHub 저장소에서 자동 빌드

프로젝트에는 `.github/workflows/build.yml`이 포함되어 있습니다. 비공개 저장소의 `main` 브랜치에 올리면 GitHub Actions가 자동으로 빌드합니다.

1. GitHub 저장소의 `Actions` 탭을 엽니다.
2. 가장 최근의 `Build Fabric mod` 실행을 엽니다.
3. 아래쪽 `Artifacts`에서 `crouchlock-1.0.0`을 내려받습니다.

비공개 저장소의 코드와 Actions 결과물은 해당 저장소에 접근 권한이 있는 사용자만 볼 수 있습니다.
